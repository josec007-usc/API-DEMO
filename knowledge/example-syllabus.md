## Course description

This sample course introduces students to responsible use of web APIs and generative AI. Students learn how clients, servers, secrets, requests, and responses work together.

## Learning objectives

By the end of the course, students should be able to explain why an API key must not be placed in browser code, send a structured request to an API, interpret a JSON response, and evaluate an AI answer against a source.

## Example policies

Students should verify AI-generated information against course materials. Never commit API keys, passwords, or other credentials to GitHub. Questions about grades or personal circumstances should be directed to the instructor rather than entered into the chatbot.
