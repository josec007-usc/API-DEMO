# Assignments

Source document: `Assignments.docx`

Assignments

## Exercise 1 - Hello World

Create a simple Hello World app. Start with with the Swift example template and create a text message that will display on the user’s screen when the app runs. Change as many things as you possibly can to differentiate it from the default “Hello World” template. This is your opportunity to get really creative with the design elements of SwiftUI. Once this is complete, test run the app in the Xcode device simulator.

Each exercise will be submitted to Brightspace as a .zip of the entire project folder, accompanied by a paragraph description.

## Exercise 2 - Clicker Game

Using what you know about variables, functions, structs, conditionals and other programming fundamentals, create a simple clicker game. The app should display a counter of how many times the user has clicked the icon on the screen. The user should also be presented with awards after certain click achievements have been met.

Each exercise will be submitted to Brightspace as a .zip of the entire project folder, accompanied by a paragraph description.

## Exercise 3 - UI and UX

Create button and screen based navigation. Imagine the type of app you would like to build and create a title screen, a login page, and an onboarding flow. The screens will be navigated through using buttons, input fields, and swipe gestures. Design your own sprites for some of the buttons and backgrounds. Test run the app in the Xcode device simulator. If that is successful, attempt to build it to your iPhone.

Each exercise will be submitted to Brightspace as a .zip of the entire project folder, accompanied by a paragraph description.

## Exercise 4 - Touches and Gestures

Design an app that takes advantage of touch states rather than traditional button based UI. Consider the affordances of touch duration, gestures, and multiple touches at once. Present the user with an interface that necessitates this experience and offers an intuitive, easy to use benefit over other types of UX.

Each exercise will be submitted to Brightspace as a .zip of the entire project folder, accompanied by a paragraph description.

## Exercise 5 - Sound and Haptics

Create an application that incorporates sound and haptic feedback. This can be a new creation or a polish pass on previous exercise. The submission should include a title screen, sound effects, haptic feedback, and music. Create original sprite assets as needed. You may use either original or free use audio assets. Make sure the build runs well on your phone.

Each exercise will be submitted to Brightspace as a .zip of the entire project folder, accompanied by a paragraph description.

## Midterm Project - Data Sets (group)

Working in groups of 4, develop an app that utilizes an internal or external dataset. This set could be data collected manually, created by users, or an external database. Display the data in a meaningful way. Design the user interactions with intentionality. Consider the type of actions the user would want or need to do with this particular type of data.

The midterm is a polished project, developed over a 3 week sprint, with milestones along the way. The focus here will be on rapid development and iterative design. The midterm will be submitted via a GitHub repo, accompanied by a paragraph description. Every student in a group project must submit a link to the assignment, and have made meaningful contributions to the repo. The midterm is due one hour before class and builds must be bug free. Everyone in the group must submit the work to Brightspace in order to receive credit. The app needs to build to your phone without issues.
